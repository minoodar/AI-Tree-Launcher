💻 How to Install in Chrome (Developer Mode)

Download this repository and unzip the file (or use git clone).

Open Google Chrome and type chrome://extensions/ in the address bar.

Turn on Developer mode using the toggle switch in the top-right corner.

Click the Load unpacked button that appears.

Select the project root folder (the folder containing the manifest.json file).

That's it! The floating 4-ring workspace will now appear on your web pages.
