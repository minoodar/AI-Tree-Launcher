# AI-Tree-Launcher
Floating orbital bookmark launcher with AI integration, quick notes, and to-do system
راهنمای نصب دستی را برای کاربران بنویسید تا بدانند چطور از کدهای شما استفاده کنند:

ابتدا کدها را دانلود و از حالت فشرده RAR خارج کنید.

مرورگر کروم را باز کرده و به آدرس chrome://extensions/ بروید.

گزینه Developer mode را از گوشه بالا سمت راست روشن کنید.

روی دکمه Load unpacked کلیک کرده و پوشه Ai-orbit-dual انتخاب کنید.

پس از نوشتن این متن، تغییرات را Commit کنید.
