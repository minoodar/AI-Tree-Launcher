## 🇺🇸 English
### 🚀 AI Tree Launcher v34.0 — Aura & Voice Evolution
This major release fundamentally enhances the orbital workspace with zero-dependency native integrations and a completely revamped visual organization system — all while maintaining our pure **Vanilla JS architecture** and **60fps Eco-Mode performance**. 

#### 🌟 Key Features
* **🎙️ Native Omnilingual Voice Engine:** Hands-free, low-latency voice dictation utilizing Chrome's native Web Speech API. No heavy external libraries required.
* **✨ 15-Tier Visual "Aura" System:** Assign bookmarks to 15 specialized categories (AI, Finance, Dev Tools, etc.). Categorized links generate a dynamic visual "Aura" for distinctive identification.
* **🔍 Tag-Based Deep Search & Web Engine:** Instantly isolate relevant bookmarks by typing category tags, alongside a comprehensive multi-engine web search manager.
* **🌍 Five-Language Experience:** The ecosystem now fully supports English, Spanish, Persian, German, and French.
* **🖥️ Ergonomic Smart Studio:** The notepad monitor placement has been highly optimized to dock without obstructing your primary workflow.

#### ⚡ Performance Highlights
**Pure Vanilla JS** • Zero heavy dependencies • **Native browser API integration** • 60fps Eco-Mode • **Extended Multilingual Support**

#### 💻 Installation (Developer Mode)
1. Clone `minoodar/AI-Tree-Launcher` or download the ZIP.
2. Go to `chrome://extensions/` and enable **Developer mode**.
3. Click **Load unpacked** and select the project folder.
